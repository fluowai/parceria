# Parceria Home Care

Site institucional responsivo com serviços, perguntas frequentes e contato pelo WhatsApp.

## Executar

Sirva a pasta `dist` com qualquer servidor estático:

```bash
python3 -m http.server 8080 --directory dist
```

Abra http://localhost:8080. Sem instalação ou build.

## Publicar

Configure `dist` como diretório público na hospedagem. A página usa fontes do Google Fonts e imagens locais.
